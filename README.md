# gigwork

ギグワーカー（配達員・軽貨物ドライバーなど、複数プラットフォームを掛け持ちして働く人）向けの収益管理カレンダーアプリ。

日々の収入をプラットフォームごとに記録し、月・週・日単位で「稼げているか」を一目で把握できることを目的とする。広告・課金・データ収集による収益化は行わず、開発者側のポートフォリオ／案件受注の実績提示を主目的とする。

## 現状

`app/` 配下に、コア機能（カレンダー入力・ヘッダー集計・固定費逆算アラート・支出・リザルト・設定・スクショ自動入力）を実装した最小構成のPWAを用意。ビルド不要のVanilla JS + localStorageのみで動作し、サーバー・バックエンド・外部API呼び出しは一切ない。

### 動かし方

ローカルでは `app/index.html` を任意の静的サーバーで配信するだけ（例: `npx serve app`）。file://では manifest/service worker が動かないため、必ずHTTP経由で開くこと。

### 公開（GitHub Pages、無料）

`.github/workflows/deploy-pages.yml` を用意済み（このリポジトリのデフォルトブランチへのpushをトリガーにしている）。リポジトリの Settings → Pages → Source を「GitHub Actions」に切り替えれば、以後 `app/` への変更がpushされるたびに自動で `https://<ユーザー名>.github.io/gigwork/` に公開される（サーバー費用・API利用料ともに発生しない）。

## 要件定義

確定した要件は [REQUIREMENTS.md](./REQUIREMENTS.md) を参照。

- 入力（プラットフォーム自由登録・連続入力）
- カレンダー（Apple/Google準拠の操作性、日別合計＋プラットフォーム別ドット）
- ヘッダー（収入・固定費／変動費・黒字赤字・目標稼働額）
- 家計簿（固定費・変動費の動的追加登録）
- シェア機能（月末レポート画像の自動生成）
- ホーム画面（PWA、ウィジェット非対応）
- マネタイズなし（広告・課金・データ収集による収益化はしない）
- データ保存はlocalStorageのみ（DB・課金導線は今回のスコープ外）

## スコープ外（今回作らないもの）

要件定義上、以下は明示的にスコープ外としている。

- DB接続・バックエンド
- 課金導線（モック含む）
- 広告表示
- ユーザーデータの外部送信・収集
